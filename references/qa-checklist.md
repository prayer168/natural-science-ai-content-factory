# 交付前 QA Checklist

## 內容
- [ ] 年級與單元正確
- [ ] 每題對應明確學習目標
- [ ] 正確答案可由題目或證據支持
- [ ] 誘答不是荒謬選項
- [ ] 無雙重否定與模糊量詞
- [ ] 圖表/實驗題資料完整
- [ ] 科學敘述已查證或標記待查
- [ ] `verified` 題目至少有一個已開啟且支持列明主張的來源
- [ ] 沒有 `draft`、`needs_review` 或 `blocked` 題目被放入待上傳批次

## 雙平台一致性
- [ ] Kahoot 與 Wayground 來自同一 canonical id
- [ ] 平台轉譯後未改變正解
- [ ] 平台轉譯後未改變學習目標
- [ ] 互動題降級時有 fallback
- [ ] manual_required 已列出
- [ ] 程式驗證 hook 已執行，`驗證報告.md` 為 PASS

## 匯入
- [ ] 已取得當次官方 template 或明確標記非官方匯入檔
- [ ] 空白題、答案編號、時間、欄位名稱已檢查
- [ ] 檔名安全且活動不混檔
